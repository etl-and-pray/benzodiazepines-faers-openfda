# Бензодиазепины в FAERS (openFDA)

Учебный аналитический проект: как в добровольных отчётах о нежелательных реакциях (FDA FAERS) проявляются **зависимость, злоупотребление, синдром отмены и передозировка** при четырёх бензодиазепинах (алпразолам, диазепам, лоразепам, клоназепам), и связано ли присутствие **опиоидов** в отчёте с передозировкой.

Основной файл: [`benzo_faers_final.ipynb`](benzo_faers_final.ipynb) (сохранён с результатами, читать можно без запуска).

## Основные результаты

- **Злоупотребление:** алпразолам 23,0% и диазепам 17,3% отчётов когорты против 10,9% (лоразепам) и 9,1% (клоназепам). По всей базе ROR около 19 и 22 против 7.
- **Передозировка и токсичность:** диазепам лидирует (30,0% отчётов широкой группы против 17-22%; ROR 8,4). После поправок ОШ диазепама против алпразолама 1,69.
- **Опиоиды:** ОШ передозировки или токсичности 1,42 (95% ДИ 1,32-1,53) после поправок на возраст, пол, год, препарат, число и классы сопутствующих; 1,39 (1,22-1,58) без отчётов с флагом дубля. Антидепрессанты (1,97) и z-препараты (1,65) связаны сильнее.
- **Синдром отмены:** 2-3% отчётов, между препаратами почти не различается.
- Все результаты описывают **ассоциации в добровольных отчётах**, а не причинные эффекты и не частоты в популяции. Подробности в разделе «Ограничения» ноутбука.

## Данные

[openFDA `drug/event`](https://open.fda.gov/apis/drug/event/), отчёты за 2019-2025 годы.

- **Когорта:** отчёты, где бензодиазепин указан как подозреваемый препарат; подвыборка до 2000 отчётов на препарат и год (13-34% доступных), 21 396 отчётов.
- **Сигналы безопасности (PRR, ROR):** считаются по всей базе (около 10 млн отчётов) через `count`-запросы.

Загруженные данные в репозиторий не входят (папка `data/` игнорируется).

## Методы

- группы реакций по терминам MedDRA (зависимость, злоупотребление, отмена, передозировка узкая и широкая);
- доли с доверительными интервалами Уилсона;
- классы сопутствующих препаратов (опиоиды, антидепрессанты, антипсихотики, габапентиноиды, z-препараты, стимуляторы и нелегальные, алкоголь);
- проверка устойчивости к отчётам с флагом `duplicate`;
- логистическая регрессия с поправками (собственная реализация на numpy, проверена на точной таблице 2×2);
- PRR и ROR с критериями Эванса, в том числе для объединённых групп терминов.

## Как запустить

```bash
pip install pandas numpy matplotlib requests jupyter
jupyter notebook benzo_faers_final.ipynb
```

1. Получите бесплатный ключ openFDA: https://open.fda.gov/apis/authentication/
2. Kernel → Restart & Run All. Ключ можно ввести при запросе или задать переменной окружения `OPENFDA_API_KEY`. В ноутбуке он не сохраняется.
3. Первая загрузка занимает долго (около 56 000 отчётов и около 90 count-запросов). Результаты кэшируются в `data/`, повторный запуск идёт без сети.

Цифры в ноутбуке получены на данных, загруженных 15.10.2026. При перекачке они могут немного отличаться.

## Ограничения

Добровольные отчёты, подвыборка, не учтены показания и причина обращения, дубли обработаны не полностью, PRR и ROR считаются по присутствию препарата в любой роли относительно всей базы. Проект учебный и не содержит медицинских рекомендаций.

## Источник

Данные: U.S. FDA, openFDA. Проект не связан с FDA и не одобрен ею.
